# 随项目提供的网页字体

本目录提供用于网页预览与图片导出的字体资源。字体按需从本地文件加载，不依赖在线字体 CDN；部署时请连同本目录一起上传。

| 网页选项 | 原作者项目 | 资源 |
| --- | --- | --- |
| 霞鹜文楷 | https://github.com/lxgw/LxgwWenKai | LXGWWenKai-Regular.woff2 |
| 得意黑 | https://github.com/atelier-anchor/smiley-sans | SmileySans-Oblique.woff2 |
| 站酷快乐体 | https://github.com/google/fonts/tree/main/ofl/zcoolkuaile | ZCOOLKuaiLe-Regular.woff2 |
| 马善政毛笔楷书 | https://github.com/google/fonts/tree/main/ofl/mashanzheng | MaShanZheng-Regular.woff2 |

霞鹜文楷、站酷快乐体与马善政字体仅转换为 WOFF2 网页格式，保留全部字形；得意黑采用作者提供的 WOFF2。未对子集或字形做修改。

原项目的版权声明与 OFL 全文见对应的 `*-OFL.txt`。原始下载地址及 SHA-256 记录见 `sources.json`。字体权利属于原作者，网页项目不改变字体的许可。
