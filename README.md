# 纸间 · 小红书排版

一个可部署到 GitHub Pages 的小红书图文排版网页。粘贴标题和正文，选择模板，生成 3:4 卡片，适配电脑、平板和手机浏览器使用。不需要安装依赖或运行 npm 构建。

## 支持的功能

- 独立的标题、正文输入框，标题支持手动换行。标题下方直接提供 24～120 字号滑块、A− / A＋按钮、数值输入和恢复默认，与样式设置同步。
- 标题与正文可分别选择字体、加粗和斜体。新增内置「霞鹜文楷、得意黑、站酷快乐体、马善政毛笔楷书」，保留黑体、宋体和楷体，也可分别上传或选择自己的字体。
- 自动分页，实时预览 3:4 卡片；长标题保留所选字号，必要时跨页显示并提示。
- 67 套内置风格模板，本次新增 12 套「柔美」风格，含奶油蝴蝶结、蕾丝信纸、郁金香、樱花、珍珠、芭蕾、雾紫蝶梦、粉格野餐、玫瑰、雏菊、水彩与浅粉记事本；本次新增的 12 套排在模板库最前面，也可点击「柔美」单独查看。支持调整配色、字体、字号、间距与布局，并保存自己的预设，详见 `模板目录.md`。
- 正文输入区提供 16～72 字号滑块、A− / A＋、数值输入与恢复默认；统一调整全文，正文中的小标题按比例缩放。标题（含正文小标题）与正文的字号、颜色、不透明度可分别修改，编辑区与「自定义」面板同步。
- 全部内置模板可自定义背景色、底图不透明度、纹样不透明度；不透明度 0% 隐藏、100% 完整显示，淡化至白底。上传图片的不透明度独立控制，支持草稿、撤销重做、「我的风格」与工程导入导出。
- 上传图片作为卡片底图，调整图片呈现方式；也可导入本地字体。
- 导出 1080 × 1440 或 2160 × 2880 像素的 PNG / JPEG，支持单张导出、一键逐张下载全部 PNG / JPG、系统批量分享（依浏览器支持）和可选 ZIP 打包。
- 在当前浏览器保存草稿，通过项目 JSON 文件导出、导入和转移作品。
- 网页内不设会员、收费解锁或导出水印。
- 卡片左下角不显示署名文字，旧草稿和旧工程中的署名也不会再出现在图片中；右下角页码仍可在卡片细节中开关。

模板库参考常见小红书卡片风格重新设计，提供多种可编辑版式，并非原站全部模板的逐像素复制。上传的底图是一张完整图片，图片里原有的文字不能直接编辑；建议上传无字底图，再在网页中叠加标题、正文。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，首次使用建议选择 Public。
2. 将本文件夹内的**全部文件和子文件夹**上传到仓库根目录。打开仓库时应直接看到 `index.html`，不要再套一层 `xiaohongshu-card-studio` 文件夹。隐藏文件 `.nojekyll` 也一并保留。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中将 Source 设为 **Deploy from a branch**。
5. Branch 选择 **main**，目录选择 **/ (root)**，点击 **Save**。如果仓库默认分支另有名称，选择实际上传文件所在的分支。
6. 等待部署完成，打开 Pages 页面提供的网址。通常形式为 `https://你的用户名.github.io/仓库名/`。

之后更新网页，只需覆盖仓库中的对应文件并提交。若仍看到旧版，可刷新页面或稍后重试。

## 本地预览

也可以用任意静态文件服务器打开本文件夹。例如安装了 Python 时，在文件夹中执行 `python -m http.server 8080`，然后访问 `http://localhost:8080`。推荐通过本地服务器或 GitHub Pages 使用，以获得更稳定的浏览器存储和下载行为。

## 手机、平板导出

建议用 Safari、Chrome 或 Edge 等完整浏览器打开链接。生成图片后点击「逐张下载全部图片」，可直接下载各页 PNG / JPG，无需解压；浏览器可能要求允许多个文件下载。单张图片也可以下载保存；浏览器支持多文件系统分享时，可点击「分享全部图片」，具体存储操作取决于系统分享面板。若图片在新页面打开，可长按图片保存。ZIP 通常保存到系统“文件”或“下载”中，解压后即可获得整组图片。微信等应用内置浏览器的下载能力可能有限，可改用系统浏览器打开。

## 保存与素材

- 草稿保存在**当前设备、当前浏览器**，不会自动跨设备同步。清理网站数据、无痕模式或更换浏览器可能丢失本地草稿，重要作品请导出项目 JSON 备份。
- 换设备时，将项目 JSON 文件传到另一台设备，再在网页中导入。字体如未随项目恢复，请重新导入对应字体文件。
- 自定义字体由浏览器本地加载，导出前请等待字体加载完成。公开分享图片时，请使用有相应使用权限的图片与字体。
- 新增的 4 款字体随项目保存在 `fonts/`，预览和导出前会等待所选字体加载完成。部署或复制项目时请保留整个 `fonts/` 文件夹，其中含原作者的 OFL 许可及来源记录。
- 这是静态排版工具，不包含托管 AI 服务、账户云同步或一键发布到小红书。
